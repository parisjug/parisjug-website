Paris JUG Academy le 12/01/2027

Les candidatures sont ouvertes !

La 13ème Paris JUG Academy aura lieu le 12/01/2027. Six personnes présenteront des sujets de 15mn, le public désignera alors un gagnant ou une gagnante. Cette session sera parrainée Jean-Philippe BEMPEL, Java Champion .
Les candidatures sont ouvertes jusqu’au dimanche 22/11/2026 (minuit à Paris).

  • - Tous les sujets sont acceptés ;
  • - La première candidature soumise est systématiquement acceptée ;
  • - Une candidature est tirée au hasard ;
  • - Nous annoncerons le résultat le 26/11/2026.

Les candidats peuvent bénéficier d'un accompagnement dans leur préparation lors de 4 soirées entre le 26/11/2026 et le 12/01/2027.
